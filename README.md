# Expense Tracker Mini Project

## Overview

The Expense Tracker is a web-based mini project developed using HTML, CSS, and JavaScript to help users efficiently manage daily financial activities. It allows users to record income and expenses, monitor transaction history, and automatically calculate total balance. This project demonstrates practical implementation of front-end development concepts through a real-world financial management system.

## Objectives

* To develop a simple and interactive expense management system
* To understand DOM manipulation and event handling
* To apply JavaScript for dynamic data processing
* To create a responsive and user-friendly interface

## Key Features

* Add income and expense transactions
* View transaction history instantly
* Automatic balance calculation
* Separate display of income and expenses
* Delete transactions easily
* Clean and responsive design

## Technologies Used

* HTML for structure
* CSS for styling
* JavaScript for functionality

## Learning Outcomes

This project enhances knowledge in web development, problem-solving, user interaction, and financial tracking concepts, making it an effective academic mini project for skill development.
